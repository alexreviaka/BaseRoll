## Key Features

1. **Decentralized & Transparent**: All payments recorded on-chain
2. **Automated**: Schedule recurring payments that execute automatically
3. **Multi-Token**: Support for ETH, USDC, DAI, and custom ERC-20 tokens
4. **Upgradeable**: Proxy pattern allows future improvements
5. **Base Pay**: Integrated with Base Pay for enhanced payment features
6. **Analytics**: Real-time dashboard with payment insights
7. **Secure**: Audited contracts, role-based access control
8. **User-Friendly**: Modern UI with excellent UX
