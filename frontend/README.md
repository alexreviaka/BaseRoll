# BaseRoll Frontend

React frontend for BaseRoll decentralized payroll system.

## Features

- Company dashboard
- Employee management
- Payment processing
- Web3 wallet integration
- Base blockchain connectivity

## Setup

```bash
# Install dependencies
yarn install

# Configure environment
cp .env.example .env

# Run development server
yarn dev
```

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- ethers.js
- React Router
- Axios

## Build

```bash
yarn build
```
