# Frequently Asked Questions

## General

**Q: What is BaseRoll?**
A: BaseRoll is a decentralized payroll system built on Base blockchain.

**Q: Why use blockchain for payroll?**
A: Blockchain provides transparency, automation, and lower costs.

## Technical

**Q: Which networks are supported?**
A: Base Mainnet and Base Sepolia testnet.

**Q: What tokens can I use for payments?**
A: ETH, USDC, DAI, and any ERC-20 token.

**Q: How much does it cost?**
A: Only gas fees (~$0.01-0.10 per transaction on Base).

## Troubleshooting

**Q: Transaction failed?**
A: Check wallet balance and network connection.

**Q: Employee not showing?**
A: Wait for blockchain confirmation (usually < 5 seconds).
