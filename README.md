# BaseRoll

Decentralized payroll on Base blockchain.

## Features
- Company management
- Employee onboarding  
- Automated payments
- Base Pay integration

## Tech Stack
- Solidity, Hardhat, OpenZeppelin
- FastAPI, MongoDB
- React, Vite, Tailwind

## Setup
```bash
npm install
npx hardhat compile
cd backend && pip install -r requirements.txt
cd frontend && yarn install
```
